# UI Research

Источники: Mobbin (ios-скрины Saturn Calendar, ClassPass, Grab Driver, Turo, Wise, Nike Run Club, Expedia, Runna, Structured, Outlook, Preply), UX-гайды (Courier notification center, ScreensDesign, ui-patterns schedule, campusM UX ebook, Texas Law dashboard case, MyAUC case, williamalexander.co «Student Portal UX»), скиллы: fluid-functionalism, better-writing, laws-of-ux.

Общие выводы по референсам:
- Мобильное расписание у лучших это НЕ 7-колоночная сетка: сверху горизонтальный day-picker (недельная полоса дат), снизу agenda-list с группами «Сегодня / Завтра / дата» (ClassPass, Grab Driver, Saturn). Сетка — только на десктопе.
- Inbox это табы/фильтры + строки «иконка-тип · заголовок · 1-2 строки тела · относительное время» (Turo, Wise). Непрочитанное = точка + чуть жирнее заголовок, без лишнего (Courier).
- Домашний экран у студенческих продуктов это «пульт»: текущее/следующее событие крупно + карточки-виджеты (Saturn, Preply, Texas Law dashboard, MyAUC). 71% discovery rate у Torrens MyHub — дашборд реально главный экран.
- Действия из строк там, где рука: свайп/long-press на мобиле, hover на десктопе; mark all read в шапке.
- Типовые ошибки вузовских порталов: организация по оргструктуре вуза а не по задачам студента, перегруз информацией, устаревшие данные, нет статус-трекинга заявок (UTS case: непрозрачность трекинга порождает дубли заявок).

## Экран 1: Вход

- Как выглядит: центрированная карточка на «живом» фоне (шейдерная подложка из components/slides/ascii-shader или мягкий градиент), логотип-знак продукта, поля логин/пароль, кнопка «Войти», под карточкой карточка тестовых аккаунтов (для жюри).
- Элементы: знак «Д» + название «Деканат», подпись «концепт для конкурса, не официальный сервис», Input, Button, ошибка входа баннером.
- Анимации: reveal-landing на появлении карточки; кнопка — спиннер только на время проверки; ошибка — мягкий вход баннера.
- Состояния: пустые поля (кнопка активна, ошибка показывается после сабмита), неверный пароль, успех → редирект на главную.
- Ошибки: «Неверный логин или пароль» — без уточнения что именно неверно (безопасность).
- Подсказки: список тестовых аккаунтов с копированием в один тап.
- Компоненты: Card, Input, Button, Banner, springs.
- Копирайт: «Деканат» / «Всё для учёбы в одном месте» / «Концепт для конкурса».
- Цвета: тёмный акцентный фон, карточка --card.

## Экран 2: Главная (дешборд)

- Как выглядит: приветствие «Добрый день, Имя» + дата; hero-карточка «сейчас/следующая пара» с отсчётом; ряд виджетов: окно сегодня / средний балл / активные заявки / ближайший дедлайн; лента «важное» из уведомлений; быстрые действия (заказать справку, расписание).
- Элементы: Card-виджеты, Badge статусов, Lucide-иконки, FastLink-навигация.
- Анимации: reveal-product на входе; виджеты появляются reveal-items каскадом; отсчёт времени — number transition.
- Состояния: нет пар сегодня → «Сегодня занятий нет» + ближайший учебный день; нет заявок → приглашение создать.
- Ошибки: не применимо (данные сида), но error boundary на страницу.
- Компоненты: Card, Badge, Button, FastLink, type-scale (display/title/body/micro).
- Копирайт: «Идёт сейчас» / «Следующая» / «Окно N мин» / «Средний балл» / «До дедлайна».
- Цвета: нейтральный фон, акцент --primary только на ключевом действии и статусах изменений.

## Экран 3: Расписание

- Как выглядит: паттерн ClassPass/Grab — сверху недельная полоса дат (7 дней, сегодня выделен, точки под датами с парами и маркер изменений), под ней agenda-list по выбранному дню; на десктопе справа можно неделю целиком, но базово тот же список; свайп/стрелки по дням; «окна» между парами как отдельные приглушённые строки.
- Элементы: day-picker (кастомный, на useFluidHover), строки пар: № пары, время начала–конца, название, тип (лекция/семинар/лабораторная), аудитория, преподаватель; бейджи изменений «Перенесено», «Отменено», «Замена» со старым значением зачёркнуто.
- Анимации: смена дня — контент crossfade+сдвиг в сторону свайпа (spring.fast/moderate); выбор даты — highlight глиссирует в полосе.
- Состояния: выходной/пустой день → «Занятий нет»; изменённая пара — заметный бейдж; отменённая — приглушена.
- Компоненты: Card, Badge, Tabs (Сегодня/Неделя), springs, reveal-items.
- Копирайт: «Пн 24 ноября» / «1 пара · 9:00–10:35» / «Перенесено в ауд. 512» / «Отменено» / «Окно 1 ч 35 мин».
- Цвета: тип занятия — цветная метка (лекция синяя, семинар зелёная, лабораторная янтарная), изменения — amber/destructive.

## Экран 4: Успеваемость

- Как выглядит: сверху сводка — средний балл крупно, закрыто зачётов/экзаменов, блок «Сессия» с датами и предметами; ниже список дисциплин семестра: название, тип итога, оценка (число или «зачёт»/«незачёт»), прогресс-баллы; таб или аккордеон на прошлые семестры.
- Элементы: Card сводки, список дисциплин (строки), Badge итога, мини-прогресс.
- Анимации: числа pop-in (transitions-dev паттерн) на первом показе; reveal-items на списке.
- Состояния: оценок пока нет → «Промежуточные баллы появятся после первых контрольных».
- Компоненты: Card, Badge, Tabs, Accordion для семестров.
- Копирайт: «Средний балл» / «Экзамен 14 января» / «Зачёт» / «Автоматом не выйдет» (если балл < порога) — аккуратно, без паники.
- Цвета: 5/4/3/зачёт — разные оттенки (success для 5 и зачёта, нейтраль для 4, amber для 3).

## Экран 5: Заявки и справки

- Как выглядит: список заявок карточками «как заказы в доставке»: название, №, дата подачи, статус-бейдж, таймлайн статусов (Подана → Принята → В работе → Готова / Отклонена) с датами, блок «где забрать» когда готова; кнопка «Новая заявка» → экран создания: тип справки (об обучении, для военкомата, о стипендии), способ получения (онлайн PDF / в деканате), для заявления — шаблон + свободный текст.
- Элементы: Card заявки, вертикальный stepper статусов, Select/Radio для типа, Textarea, Button.
- Анимации: создание — кнопка со спиннером (операция реальная), после успеха — баннер «Заявка подана» и карточка появляется reveal; раскрытие карточки — layout-анимация.
- Состояния: пусто → «Пока ни одной заявки» + CTA; отклонённая — причина; готова — куда идти и срок хранения.
- Ошибки: пустой текст заявления → подсветка поля; сеть — ошибка в баннере формы.
- Компоненты: Card, Badge, Stepper (кастомный на type-scale), Select, RadioGroup, Textarea, Field, Button, Dialog/мобайл-sheet для создания.
- Копирайт: «Справка об обучении» / «Готова, можно забрать в деканате, каб. 214» / «Обычно готово за 3 рабочих дня».
- Цвета: статусы — нейтральные для в процессе, success для готовой, destructive-light для отклонённой.

## Экран 6: Уведомления

- Как выглядит: паттерн Turo/Wise — шапка с заголовком + «Прочитать все», фильтр-чипы (Все / Непрочитанные / Расписание / Заявки / Дедлайны), группы «Сегодня / Вчера / Ранее», строки: иконка типа, заголовок, 1-2 строки тела, относительное время, точка непрочитанного; тап → помечается прочитанным и ведёт в раздел.
- Элементы: чипы-фильтры, строки уведомлений, иконки Lucide по типу (CalendarClock, FileCheck, AlarmClock, Megaphone).
- Анимации: mark-read оптимистично (точка гаснет, заголовок легчает); mark-all — каскад; фильтр — crossfade списка.
- Состояния: пусто → «Всё прочитано»; пустой фильтр → «Нет уведомлений этого типа».
- Компоненты: Card/строки, Badge-счётчик, Button, Tabs/чипы.
- Копирайт: «Пара перенесена на 14:50» / «Справка готова» / «До конца приёма заявлений 2 дня».
- Цвета: нейтральный фон, непрочитанное — точка --primary.

## Экран 7: Профиль

- Как выглядит: шапка с аватаром-инициалами, ФИО, группа/факультет/курс; карточка «студенческий» (вымышленный №, срок); контакты своего деканата (кабинет, часы, почта); выход.
- Элементы: аватар (initials), списки фактов, Button выход (destructive-ghost).
- Анимации: reveal-product.
- Состояния: обычное.
- Компоненты: Card, Button.
- Копирайт: «Студенческий билет» / «Деканат ФИТ, каб. 214, пн–пт 10:00–17:00».
- Цвета: нейтральные.

## Навигация и общий каркас

- Мобильный: нижний таббар (5 разделов: Главная, Расписание, Оценки, Заявки, Ещё→Уведомления/Профиль) — по research 4 основных таба + 5-й «ещё». Выбранный таб — иконка+лейбл с весом без рефлоу.
- Десктоп: тот же контент в центрированной колонке ~960px или лёгкий sidebar слева; нижний таббар скрывается.
- Моушн-система: springs fast/moderate/slow, reveal-классы, FluidHoverHighlight в списках, вес без рефлоу.
- Типографика: type-scale роли (display/title/subtitle/body/caption/micro), 2 цвета текста, без uppercase.
- 360px: строки пар не сжимаются в колонку — время слева колонкой 56px, контент справа.
