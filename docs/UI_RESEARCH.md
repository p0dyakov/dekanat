# Как устроены экраны

Посмотрели примеры расписания и уведомлений в [Mobbin](https://mobbin.com). Для компонентов использовали [Fluid Functionalism](https://github.com/mickadesign/fluid-functionalism).

| Источник | Что посмотрели | Что перенесли |
| --- | --- | --- |
| ClassPass, Saturn, Grab Driver | Полоса дат над списком занятий | Выбор дня недели и список занятий на этот день |
| Turo, Wise | Фильтры по темам, время и точка непрочитанного | Фильтры и отметки о непрочитанном |
| MyAUC, Texas Law | Сводка ближайших событий на главной | Ближайшая пара, средний балл и сроки |
| fluid-functionalism | Меню и поля ввода | Общие компоненты для разделов |
